# Demo script (target: 2 minutes 30 seconds)

1. **0:00–0:15 — Problem.** Explain that people lose time when deadlines collide or plans are disrupted.
2. **0:15–0:35 — Product.** Introduce Deadline Rescue as a task-aware planning and recovery assistant. Clarify that the Alexa+ experience is a simulation and the MCP server is self-hosted.
3. **0:35–1:00 — Real task state.** Create or show a task and show that it persists after refresh/restart.
4. **1:00–1:25 — Focus planning.** Provide a realistic available-time window and show scheduled versus deferred work.
5. **1:25–1:50 — Disruption recovery.** Simulate lost time and show the revised plan and explanation.
6. **1:50–2:10 — MCP.** Show an actual MCP initialize/tool discovery/tool call using the running server; do not present screenshots or mock JSON as live integration.
7. **2:10–2:25 — Safety and honesty.** Mention explicit saved memory, action history, and the limits of the current Alexa+ simulation.
8. **2:25–2:30 — Close.** State the user benefit in one sentence.

Record in English, keep the video under three minutes, use original visuals/audio or properly licensed material, and ensure every shown action works in the submitted build.
